# PES Wi-Fi Auto-Login Extension

Tired of PES campus Wi-Fi logging you out every 15 minutes? This extension handles it automatically — detects session expiry and logs you back in within seconds.

## What it does
- Detects when your session expires
- Auto-fills and submits your login credentials
- No page reloads or internet interruption
- Runs silently in the background
- Save multiple accounts and switch between them from the popup

## Supported browsers
- Chrome ✅
- Edge ✅
- Brave ✅
- Firefox ❌

## How to install
1. Download the zip from the [Releases](../../releases) section
2. Extract the zip
3. Open extensions page:
   - Chrome → `chrome://extensions`
   - Edge → `edge://extensions`
4. Enable **Developer Mode** (top right toggle)
5. Click **Load unpacked** → select the extracted folder
6. Click the extension icon → enter your USN & password → Save

## Notes
- Only works on PES campus Wi-Fi
- Keep the `192.168.x.x` login tab open in the background
- Your credentials are stored locally in your browser only — nothing is sent externally
